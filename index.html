hello-world

The proving instance for the carveable-domain template. Every layer (presentation, interface, behavior, services, adapters, state, knowledge, ops) is filled with at least one working artifact. The master branch is the empty mold; this branch fills it in.

Demos

  • Hello, world Live fetch against /api/hello — proves the full layer chain.
  • RunsNative · Variants Component variants via importmap. The dogfood demo for the framework-web docs page.
  • Bundle test (no importmap) Same components, served from a pre-built vendored bundle.
  • hello-agent surface Interactive form — the "door" an agent knocks on to invoke the same service.
